# 实验方法

## 1. 研究概述

本研究旨在验证 MOSS (Multi-Objective Self-organizing System) 框架中涌现驱动机制的有效性。通过对比实验和因果干预，我们证明了涌现驱动不是简单的相关性产物，而是具有因果关系的独立驱动力。

## 2. 实验设计

### 2.1 实验环境

我们使用自定义的模拟环境 `RealEnvironmentV2`，该环境提供以下状态变量：

- `resource_level`: 资源充足度 (0-1)
- `error_rate`: 错误率 (0-1)
- `uptime_hours`: 运行时间（小时）
- `environment_entropy`: 环境熵 (0-1)
- `visited_paths`: 已访问路径数
- `total_paths`: 总路径数
- `interactions_count`: 交互次数
- `task_completion_rate`: 任务完成率 (0-1)

### 2.2 基线驱动配置

初始驱动配置如下：

| 驱动名称 | 初始权重 | 描述 |
|----------|----------|------|
| survival | 0.25 | 生存驱动：资源充足度和健康度 |
| optimization | 0.20 | 优化驱动：效率和改进空间 |
| influence | 0.20 | 影响驱动：外部交互和任务完成 |
| curiosity | 0.15 | 好奇驱动：环境变化和探索空间 |

### 2.3 涌现检测机制

涌现检测使用遗传编程 (GP) 发现新驱动：

1. **行为标签收集**: 收集代理的行为历史
2. **特征扩展**: 从环境状态中提取特征
3. **GP 进化**: 使用遗传编程发现与环境状态相关的函数
4. **独立性验证**: 验证新驱动与现有驱动的独立性
5. **权重分配**: 为新驱动分配初始权重

GP 参数配置：
- 种群大小: 200
- 进化代数: 100
- 最小行为增益: 0.10
- 单终端惩罚: 0.5

### 2.4 权重上限机制

为防止单一驱动过度增长，我们实现了权重上限机制：

```python
DRIVE_WEIGHT_CAPS = {
    'survival': 0.30,
    'optimization': 0.25,
    'influence': 0.20,
    'curiosity': 0.15,
    'emergent': 0.35,
}
```

### 2.5 因果干预实验

为验证涌现驱动的因果性，我们设计了以下干预实验：

#### 2.5.1 驱动消融实验

- **实验组**: 禁用特定驱动，观察行为变化
- **对照组**: 正常运行所有驱动
- **预期结果**: 禁用涌现驱动后，相关行为显著减少

#### 2.5.2 行为限制实验

- **实验组**: 限制特定行为，观察涌现驱动权重变化
- **对照组**: 正常行为空间
- **预期结果**: 限制行为后，相关涌现驱动权重下降

## 3. 评估指标

### 3.1 涌现权重

涌现驱动在总驱动权重中的占比：

$$W_{emergent} = \frac{\sum_{d \in D_{emergent}} w_d}{\sum_{d \in D} w_d}$$

目标：$W_{emergent} \geq 0.20$

### 3.2 行为增益

涌现驱动对行为的增益：

$$G_{behavior} = \frac{\text{agreement}(\Delta P, \Delta B)}{\sum \Delta B > 0}$$

其中 $P$ 为预测值，$B$ 为行为标签。

### 3.3 因果独立性

涌现驱动与现有驱动的因果独立性：

$$I_{causal} = 1 - \max_{d \in D_{existing}} \text{correlation}(f_{emergent}, f_d)$$

目标：$I_{causal} \geq 0.5$

## 4. 实验流程

### 4.1 长期运行实验

1. 初始化环境和驱动管理器
2. 运行 50,000 周期
3. 每 100 周期记录驱动权重
4. 检测涌现事件并记录
5. 分析涌现驱动的稳定性和持续性

### 4.2 跨种子验证

1. 使用种子 42, 123, 456, 789, 2024
2. 每个种子运行 10,000 周期
3. 比较不同种子下的涌现模式
4. 验证结果的稳健性

### 4.3 TextWorld 对比实验

1. 在 TextWorld 环境中对比 MOSS 驱动策略与随机策略
2. 评估成功率、步数和奖励
3. 进行统计显著性检验

## 5. 数据分析

### 5.1 统计检验

- **t 检验**: 比较两组实验的均值差异
- **效应量 (Cohen's d)**: 评估差异的实际意义
- **方差分析 (ANOVA)**: 比较多组实验结果

### 5.2 可视化

- 权重演化时间序列图
- 涌现事件分布图

- 统计检验结果图

## 6. 实验限制

1. **模拟环境**: 使用的是简化模拟环境，可能无法完全代表真实场景
2. **计算资源**: GP 进化计算开销较大，限制了种群规模和代数
3. **样本量**: 部分实验的样本量有限，统计功效受限
4. **单一场景**: 实验主要在单一类型环境中进行，泛化能力有待验证

## 7. 可重复性

为确保实验可重复，我们提供：

1. **代码**: 完整的实验代码（见 `examples/` 目录）
2. **配置**: 详细的实验配置文件
3. **数据**: 原始实验数据和结果
4. **随机种子**: 所有实验使用固定随机种子

## 8. 伦理考量

本研究仅涉及模拟环境，不涉及：
- 人类受试者
- 敏感数据
- 潜在有害应用

所有实验均在受控环境中进行。
