# 盲测验证设计

**版本**: 1.0  
**日期**: 2026-04-15  
**目标**: 消除评估者偏见，确保客观验证

---

## 设计原则

### 核心原则

1. **双盲**: 评估者不知道组标签，实验者不知道评估者身份
2. **随机化**: 样本随机分配，顺序随机
3. **预注册**: 假设和方法预先公开
4. **独立**: 评估者与实验团队无关联

---

## 实验设计

### 盲测1: 涌现检测盲测

#### 目的
验证"涌现"是否可被独立检测，而非事后解释

#### 设计

**样本**: 
- A组: 真实涌现数据 (n=50)
- B组: 随机基线数据 (n=50)
- C组: 人工构造"伪涌现"数据 (n=50)

**盲测流程**:
```
1. 数据准备 (实验团队)
   - 生成3组数据
   - 去除标签，仅保留时间序列
   - 随机编号 (001-150)

2. 评估 (独立评估者)
   - 接收无标签数据
   - 对每个样本判断: 涌现 / 未涌现
   - 记录置信度 (1-5)

3. 解盲 (第三方)
   - 对比评估结果与真实标签
   - 计算准确率、召回率、F1
```

#### 判定标准

**成功** (证明涌现可检测):
- 真实涌现识别率 > 80%
- 随机基线误识率 < 20%
- 伪涌现识别率 < 50%

**失败**:
- 三组识别率无显著差异

---

### 盲测2: 因果干预盲测

#### 目的
验证因果推断不受评估者偏见影响

#### 设计

**干预**: 禁用特定drive

**样本**:
- A组: 真实干预 (禁用emergent drive)
- B组: 假干预 (禁用非关键drive)
- C组: 无干预

**盲测流程**:
```
1. 运行3组实验
2. 提取行为变化指标
3. 去除干预标签
4. 评估者判断: 哪组有显著行为变化
5. 解盲对比
```

#### 判定标准

**成功**:
- 真实干预组被正确识别 > 70%
- 假干预组误识率 < 30%

---

### 盲测3: 跨环境泛化盲测

#### 目的
验证涌现是否环境无关

#### 设计

**环境**:
- E1: 原始环境
- E2: 修改环境 (不同参数)
- E3: 未见环境 (新配置)

**盲测流程**:
```
1. 在3个环境运行实验
2. 提取涌现指标
3. 去除环境标签
4. 评估者判断: 哪些样本显示涌现
5. 解盲: 检查跨环境一致性
```

#### 判定标准

**成功**:
- 3个环境涌现识别率差异 < 15%

### 资格要求

## 盲测协议

### 预注册

```markdown
# 盲测预注册

**日期**: [日期]
**评估者**: [匿名ID]

## 假设
H1: 真实涌现可被独立检测
H2: 因果干预可被独立识别
H3: 涌现跨环境一致

## 方法
- 样本量: 150 (每组50)
- 随机化: 计算机随机
- 评估标准: [预定义标准]

## 判定
- 成功: [具体阈值]
- 失败: [具体阈值]

## 签名
[评估者签名]
```

### 数据加密

```python
# 数据匿名化
import hashlib

def anonymize(data, key):
    """使用密钥匿名化数据标签"""
    return hashlib.sha256(f"{data}{key}".encode()).hexdigest()[:8]

# 密钥由第三方保管，实验结束后公布
```

## 统计分析

### 主要指标

| 指标 | 计算 | 目标 |
|------|------|------|
| 准确率 | (TP+TN)/(TP+TN+FP+FN) | >80% |
| 召回率 | TP/(TP+FN) | >80% |
| 特异性 | TN/(TN+FP) | >80% |
| Cohen's κ | 评估者间一致性 | >0.6 |

### 统计检验

```python
from scipy.stats import chi2_contingency

# 卡方检验: 评估结果与真实标签独立性

# 成功标准: p < 0.01 (评估结果与标签相关)
```
