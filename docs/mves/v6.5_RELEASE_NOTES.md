## 关键技术

### 1. BFS 路径规划

```python
def _find_path(self, start: str, goal: str) -> List[str]:
    """BFS 路径搜索"""
    visited = {start}
    queue = [(start, [])]
    
    while queue:
        current, path = queue.pop(0)
        if current == goal:
            return path
        
        for neighbor in self.room_graph.get(current, []):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    return []
```

### 2. 混合决策

```python
def select_action(self, obs, available_actions):
    # 理解模块规划 (60%)
    planned_action = self.understanding.plan_next_action(parsed)
    if planned_action and np.random.random() > 0.4:
        return planned_action
    
    # RL 策略 (40%)
    return self._rl_select_action(obs, available_actions)
```
