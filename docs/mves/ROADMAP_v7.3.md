### 性能优化

```
优化前:
  - 每周期检查: O(n)
  - 修改频率: 0.93/周期
  - 运行时: 2.4x

优化后:
  - 批量检查: O(1) 摊还
  - 修改频率: 0.1/周期 (目标)
  - 运行时: 1.2x (目标)
```

### 智能触发

```python
class SmartTrigger:
    """智能修改触发器"""
    
    def __init__(self):
        self.performance_window = deque(maxlen=100)
        self.trend_threshold = 0.05  # 5% 趋势变化
        self.cooldown_period = 100   # 100 周期冷却
    
    def should_trigger(self, performance: float) -> bool:
        """基于趋势和冷却期触发"""
        self.performance_window.append(performance)
        
        # 检查冷却期
        if self.steps_since_last < self.cooldown_period:
            return False
        
        # 检查趋势
        if len(self.performance_window) >= 50:
            trend = self._calculate_trend()
            if abs(trend) > self.trend_threshold:
                return True
        
        return False
```
