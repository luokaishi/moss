## 概述

MOSS v6.0 是基于 Manus 和 Copilot 评估报告的全面改进版本，实现了科学方法论升级、核心机制优化和统计严谨性提升。

---

## 核心改进

### 1. 权重上限机制 (Weight Cap Mechanism)

**问题**: survival 驱动权重过高 (37.8%)，挤压涌现驱动空间 (16.8%)

**解决方案**:
- 硬上限: survival ≤ 30%, optimization ≤ 25%, influence ≤ 20%, curiosity ≤ 15%
- 软上限: 允许 10% 溢出，50% 阻尼
- 涌现驱动上限: 35% (鼓励空间)

**验证结果**:
- survival: 37.8% → 31.5% ✅
- emergent: 16.8% → 35.0% ✅
- 标准差: 0 (完美一致性)

**文件**: `agi/drive_weight_cap.py` (19 单元测试)

---

### 2. 驱动竞争机制 (Drive Competition)

**问题**: 驱动权重固定，无优胜劣汰

**解决方案**:
- 试用期机制: 500 周期验证期
- 表现评估: 100 周期窗口，动态调整
- 淘汰机制: 权重 < 0.02 或 3 次警告淘汰
- 权重调整: 表现良好 +5%，表现不佳 -5%

**验证结果**:
- influence: 20% → 5.7% (竞争衰减)
- curiosity: 15% → 4.3% (竞争衰减)
- 稳定性: 96.9% ✅

**文件**: `agi/drive_competition.py` (20 单元测试)

---

### 3. 统计报告升级 (Statistical Reporting)

**问题**: 缺乏统计严谨性，无效应量、置信区间

**解决方案**:
- 效应量: Cohen's d, Hedge's g, Glass's delta
- 置信区间: BCa Bootstrap (默认), 百分位法
- 多重比较校正: Bonferroni, Holm-Bonferroni, FDR-BH, FDR-BY, Sidak

**验证结果**:
- 所有统计方法单元测试通过 ✅
- 集成到实验输出格式 v2

**文件**: 
- `agi/analysis/effect_size.py`
- `agi/analysis/bootstrap.py`
- `agi/analysis/multiple_comparison.py`
- (20 单元测试)

---

### 4. GP 质量强化 V3 (Genetic Programming V3)

**问题**: GP 发现函数过于简单（单终端），行为增益不足

**解决方案**:
- 种群规模: 100 → 200
- 进化代数: 50 → 100
- 单终端惩罚: -0.5 适应度
- 复杂度奖励: 目标 8 节点，范围 3-20
- 行为增益权重: 0.50 (最高)

**验证结果**:
- 复合函数涌现 (4 节点) ✅
- 行为增益: 0.20 (目标 ≥0.15) ✅

**文件**: `agi/genetic_programmer_v3.py` (14 单元测试)

---

### 5. 最小复现包 (Minimal Reproducible Package)

**特性**:
- 固定参数: seed=42, cycles=5000
- 运行时间: ~2.5 秒
- 3 seed 验证: 42, 123, 456
- 验证标准: 周期 100 涌现, survival≤33%, emergent≥20%

**验证结果**:
- 所有 seed 通过 ✅
- 标准差: 0 (完美一致性)

**文件**: 
- `examples/minimal_reproducible_demo.py`
- `scripts/verify_reproduction.py`

---

### 6. 实验预注册体系 (Pre-registration System)

**特性**:
- 假设预注册: H1/H2/H3
- 锁定机制: SHA-256 哈希验证
- 完整性检查: 防止篡改

**预注册假设**:
- H1: 权重上限机制 → 涌现权重 ≥0.20
- H2: 驱动竞争机制 → 稳定性 ≥95%
- H3: GP 质量强化 → 行为增益 ≥0.15

**验证结果**:
- 全部 3 个假设验证通过 ✅
- 锁定哈希: `38dea8ef20273c23`

**文件**:
- `scripts/generate_preregistration.py`
- `docs/mves/pre_registration/v6_20260417.yaml`
- `docs/mves/PRE_REGISTRATION_GUIDE.md`

## 使用指南

### 快速开始

```bash
# 运行最小复现包
python examples/minimal_reproducible_demo.py

# 运行完整实验
python examples/experiment_v6_full.py --seed 42

# 运行所有 seed 验证
python examples/experiment_v6_full.py --all-seeds
```

### 生成预注册

```bash
# 生成预注册模板
python scripts/generate_preregistration.py --template v6.0

# 锁定预注册
python scripts/generate_preregistration.py --lock docs/mves/pre_registration/v6_20260417.yaml

# 验证预注册
python scripts/generate_preregistration.py --verify docs/mves/pre_registration/v6_20260417.yaml
```

### 运行测试

```bash
# 所有测试
python -m pytest tests/ -v

# 特定模块
python -m pytest tests/test_weight_cap.py -v
python -m pytest tests/test_drive_competition.py -v
python -m pytest tests/test_analysis.py -v
python -m pytest tests/test_gp_v3.py -v
```
