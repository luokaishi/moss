## 2. 方法论

### 2.1 关键改进 (V2版本)

针对初始版本的瓶颈，实施了三个结构性修复：

#### 修复1: 条件自我模型
```python
# 原设计 (失败)
M: state → action  # 准确率12.89%

# V2设计 (成功)
M: (state, drives) → action  # 准确率89.6%
```

**关键洞察**: 非平稳策略需要条件化输入

#### 修复2: 停滞触发机制
```python
# 原设计 (失败)
if fitness > threshold: trigger()

# V2设计 (工作)
if |Δmetric| < 0.05: trigger()  # 停滞检测
```

**关键洞察**: 元驱动应由"停滞"而非"好"触发

#### 修复3: 延长轨迹+回访奖励
```python
# 原设计 (失败)
trajectory_length = 20
extraction_period = 100

# V2设计 (成功)
trajectory_length = 200
extraction_period = 500
revisit_bias = 0.1  # 路径依赖强化
```

**关键洞察**: 目标涌现需要更长的时间尺度

## 4. 科学贡献

### 4.1 理论验证

本实验验证了以下理论假设：

1. **涌现需要多层结构**
   - 单层系统无法实现真正的涌现
   - 7层架构提供了必要的复杂性层级

2. **自我建模需要条件化**
   - 非平稳策略无法直接学习
   - 引入驱动状态作为条件后成功

3. **目标涌现需要时间尺度分离**
   - 轨迹长度200 vs 行为周期100
   - 提取周期500 vs 运行周期1

4. **元驱动应由停滞触发**
   - 而非由"好"触发
   - 这是开放式智能的关键

### 4.2 工程贡献

实现了完整的7层AGI架构：
- 总代码量: ~4,500行
- 核心模块: 12个
- 测试覆盖: 5000周期零崩溃
