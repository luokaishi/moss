## 概述

v7.4.0 是 MVES 项目的重大突破，实现了完整的元认知系统，使 Agent 能够进行自我监控、反思和元认知驱动的自我修改。

### 核心成就

- ✅ **信念系统** - 自我信念管理
- ✅ **不确定性追踪** - 认知不确定性管理
- ✅ **反思引擎** - 深度反思机制
- ✅ **元认知集成** - 统一元认知系统
- ✅ **Meta-SME 集成** - 元认知驱动的自我修改

---

## 新功能

### 1. 信念系统 (Belief System)

**文件**: `agi/meta_cognition/belief_system.py`

- 信念表示和管理
- 置信度更新
- 一致性检查
- 自我模型构建

```python
from agi.meta_cognition import BeliefSystem

bs = BeliefSystem()
bs.add_belief('self', 'can_learn', 0.8)
inconsistencies = bs.check_consistency()
```

### 2. 不确定性追踪 (Uncertainty Tracker)

**文件**: `agi/meta_cognition/uncertainty_tracker.py`

- 不确定性度量 (aleatoric/epistemic)
- 不确定性传播
- 趋势分析
- 高不确定性识别

```python
from agi.meta_cognition import UncertaintyTracker

ut = UncertaintyTracker()
ut.measure_uncertainty('perception', 0.3, 'epistemic')
trend = ut.get_uncertainty_trend('perception')
```

### 3. 反思引擎 (Reflection Engine)

**文件**: `agi/meta_cognition/reflection_engine.py`

- 多条件触发 (性能下降、不确定性增加等)
- 洞察生成
- 结论推导
- 行动项生成

```python
from agi.meta_cognition import ReflectionEngine

engine = ReflectionEngine()
reflection = engine.reflect('performance', context)
```

### 4. 元认知系统 (MetaCognition)

**文件**: `agi/meta_cognition/__init__.py`

- 统一接口
- 自我模型构建
- 不确定性摘要
- 状态导出

```python
from agi.meta_cognition import MetaCognition

mc = MetaCognition()
result = mc.step(context)
self_model = mc.get_self_model()
```

### 5. Meta-SME 集成

**文件**: `agi/meta_cognition/meta_sme_integration.py`

- 元认知驱动的自我修改
- 自我意识报告
- 智能建议生成

```python
from agi.meta_cognition.meta_sme_integration import MetaCognitiveMetaSME

mc_meta_sme = MetaCognitiveMetaSME()
result = mc_meta_sme.step(state, performance)
report = mc_meta_sme.get_self_awareness_report()
```

## 使用指南

### 基础使用

```python
from agi.meta_cognition import MetaCognition

# 创建元认知系统
mc = MetaCognition(enable_reflection=True)

# 运行步骤
context = {
    'beliefs': [{'subject': 'self', 'predicate': 'can_learn', 'confidence': 0.8}],
    'uncertainties': [{'source': 'decision', 'value': 0.5}]
}
result = mc.step(context)

# 获取自我模型
self_model = mc.get_self_model()
```

### 高级使用

```python
from agi.meta_cognition.meta_sme_integration import MetaCognitiveMetaSME

# 创建集成系统
mc_meta_sme = MetaCognitiveMetaSME()

# 运行集成步骤
for i in range(100):
    result = mc_meta_sme.step(
        state={'step': i},
        performance=0.6
    )

# 获取自我意识报告
report = mc_meta_sme.get_self_awareness_report()
print(f"Awareness level: {report['awareness_level']}")
```
