### 2. 样本量详细计算

**产出**: `docs/mves/SAMPLE_SIZE_CALCULATION.md`

**计算**:
```python
from statsmodels.stats.power import NormalIndPower

# 检测Self-Model准确率差异 (目标: 80% vs 50%)
power_analysis = NormalIndPower()
sample_size = power_analysis.solve_power(
    effect_size=1.5,  # Cohen's d
    alpha=0.01,       # Bonferroni校正
    power=0.95,       # 功效
    alternative='larger'
)
# 结果: 每组需要 ~20 样本
# 当前: 5000周期 >> 所需
```
