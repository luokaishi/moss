## 1. 主要假设检验

### 1.1 Self-Model准确率 > 50%

**假设**:
- H0: μ ≤ 50% (无改进)
- H1: μ > 50% (有改进)

**参数**:
- 效应量 (Cohen's d): 1.5 (基于5000周期实验)
- 显著性水平 (α): 0.01 (Bonferroni校正后)
- 统计功效 (1-β): 0.95
- 检验类型: 单尾

**计算**:
```python
from statsmodels.stats.power import NormalIndPower

power_analysis = NormalIndPower()
n = power_analysis.solve_power(
    effect_size=1.5,
    alpha=0.01,
    power=0.95,
    alternative='larger'
)
```

**结果**: n = 19.2 ≈ **20样本/组**

**实际**: 5000周期 >> 20，**样本量充足** ✅

---

### 1.2 Goal涌现 (数量 > 0)

from statsmodels.stats.power import NormalIndPower
