## 1. 研究假设 (Hypotheses)

### H1: 权重上限机制有效性
**零假设 (H0)**: 设置 survival 驱动权重上限 (30%) 不会显著提升涌现驱动的最终权重。  
**备择假设 (H1)**: 设置 survival 驱动权重上限 (30%) 将使涌现驱动权重从 0.168 提升至 ≥0.20。  

**判定阈值**:  
- 涌现驱动权重 ≥ 0.20: 假设成立 ✅  
- 涌现驱动权重 < 0.20: 假设不成立 ❌  

### H2: 驱动竞争机制有效性
**零假设 (H0)**: 引入驱动竞争机制不会提升涌现驱动的稳定性。  
**备择假设 (H2)**: 驱动竞争机制将使涌现驱动在 10,000 周期内的稳定性从 100% 保持，且权重方差降低 30%。  

**判定阈值**:  
- 稳定性 ≥ 95% 且方差降低 ≥ 20%: 假设成立 ✅  
- 否则: 假设不成立 ❌  

### H3: GP 质量强化效果
**零假设 (H0)**: 增加种群规模、惩罚单终端函数不会提升涌现函数的行为增益。  
**备择假设 (H3)**: GP 质量强化将使涌现函数的行为增益从当前水平提升至 ≥0.15。  

**判定阈值**:  
- 平均行为增益 ≥ 0.15: 假设成立 ✅  
- 平均行为增益 < 0.15: 假设不成立 ❌

## 2. 主要指标 (Primary Metrics)

| 指标 | 定义 | 测量方法 | 目标值 |
|------|------|----------|--------|
| **涌现驱动权重** | 涌现驱动在总权重中的占比 | 最终 checkpoint 权重值 | ≥ 0.20 |
| **稳定性** | 涌现驱动在实验周期内的持续存在比例 | 存在周期数 / 总周期数 | ≥ 95% |
| **行为增益** | 涌现驱动带来的行为多样性提升 | (新行为数 - 基线) / 基线 | ≥ 0.15 |
| **权重方差** | 涌现驱动权重的波动程度 | 标准差 / 均值 | ≤ 0.10 |

## 5. 统计方法

### 效应量计算
- **Cohen's d**: (Mean_exp - Mean_ctrl) / Pooled_SD
- **解释**: d=0.2 小效应, d=0.5 中效应, d=0.8 大效应

### 置信区间
- **方法**: Bootstrap (10,000 次重采样)
- **报告**: 95% CI 用于所有主要指标

### 多重比较校正
- **方法**: Bonferroni 校正
- **调整后 α**: 0.05 / 3 = 0.0167 (3 个主要假设)

## 7. 判定流程

### 实验成功标准
1. **主要指标**: 至少 2/3 的假设在调整后 α 水平显著
2. **效应量**: 至少 1 个主要指标达到 Cohen's d ≥ 0.5
3. **可复现性**: 3 个 seed 中至少 2 个方向一致

### 实验失败标准
1. 0/3 假设显著，或
2. 所有效应量 d < 0.2，或
3. 3 个 seed 方向不一致

### 模糊区域
- 1/3 假设显著且 0.2 ≤ d < 0.5: 需扩大样本量 (n=5) 重新验证
