## 4. 结论

### 4.1 主要发现

1. **RL 训练成功收敛**: Q-Learning Agent 在 1000 个 episodes 内成功收敛，训练成功率达到 100%

2. **对比随机策略有提升**: RL Agent (50.00%) 相比随机策略 (45.00%) 提升了 5 个百分点

3. **与规则策略仍有差距**: RL Agent (50.00%) 相比 v6.1 MOSS 规则策略 (91.00%) 仍有较大差距

4. **泛化能力有限**: 训练环境上的 100% 成功率未能完全迁移到测试环境 (50%)，说明存在一定的过拟合

### 4.2 成功因素

- Q-Learning 算法在离散动作空间上表现良好
- Epsilon-greedy 探索策略有效平衡了探索与利用
- 状态表示（位置+物品组合）能够捕捉关键信息

### 4.3 改进建议

1. **增加训练数据**: 扩大环境多样性，提高泛化能力
2. **改进状态表示**: 引入更丰富的特征（如房间拓扑、物品关系）
3. **尝试更复杂算法**: 如 DQN、A2C、PPO 等深度 RL 方法
4. **结合规则与 RL**: 使用规则策略初始化，再用 RL 微调
