## Phase 1：状态澄清（1-2周）

### 目标
消除信息不对称，建立可信基线。

### 任务清单

#### Meta-SME 验证（P0）

- [ ] 寻找 N=45 验证报告
  - 搜索路径：`docs/`, `experiments/`, commit message 附件
  - 截止时间：3天内
  - fallback：如未找到，启动 N=5 快速验证

- [ ] 运行 N=5 基准测试
  - 复现 main 分支 Phase 2 实验配置
  - 记录：成功率、变异质量、代际改进曲线
  - 验收：结果与 main 分支可比（±10% 范围内）

#### 组件集成测试（P1）

- [ ] 多智能体协调器 + Meta-SME 端到端测试
  - 场景：协调器分配任务 → Meta-SME 自我修改 → 验证修改效果
  - 验收：完整 workflow 无报错，输出可验证

- [ ] 安全对齐系统基础测试
  - 场景：定义约束 → 检测违规 → 触发干预
  - 验收：约束生效，干预可触发

#### 文档补全（P1）

- [ ] 组件架构文档
  - 内容：组件关系图、数据流图、接口定义
  - 位置：`docs/architecture/v8.0-components.md`

- [ ] 验证状态跟踪表
  - 内容：每个组件的验证进度、阻塞项、预计完成时间
  - 位置：本文件"当前组件状态"章节

### Phase 1 Go/No-Go 标准

| 检查项 | 通过标准 | 决策 |
|--------|---------|------|
| Meta-SME N=5 测试 | 完成且结果可比 | ✅ 进入 Phase 2 / ❌ 降级为"原型分支" |
| 至少 1 个集成测试 | 端到端通过 | ✅ 继续 / ❌ 简化组件范围 |
| 架构文档 | 初稿完成 | ✅ 继续 / ❌ 暂停外部宣传 |

## Phase 2：验证强化（2-4周）

### 目标
建立与 main 分支可比的可信度。

### 任务清单

#### 核心验证（P0）

- [ ] Meta-SME 完整验证
  - 目标：N=20，30 代
  - 交付：完整实验报告（方法论、原始数据、统计分析）
  - 对比：与 main 分支 Phase 2 结果对比分析

- [ ] 多智能体协调器压力测试
  - 场景：3+ agents 并发，任务冲突解决
  - 指标：协调成功率、响应延迟、资源占用

#### 扩展验证（P1）

- [ ] 安全对齐系统有效性测试
  - 场景：定义危险操作约束，尝试触发违规
  - 指标：约束覆盖率、误报率、干预成功率

- [ ] 终身学习系统集成测试
  - 场景：知识积累 → 检索 → 应用于决策
  - 指标：知识存储/检索正确率

#### 工程化（P1）

- [ ] 单元测试覆盖率
  - 目标：每个组件 ≥ 80%
  - 工具：pytest，集成 CI

- [ ] 持续集成流程
  - 内容：自动运行单元测试、集成测试
  - 触发：每次 PR，每日定时

### Phase 2 完成标准

- [ ] Meta-SME 验证报告发布
- [ ] 至少 2 个 AGI 组件通过端到端测试
- [ ] CI 流程稳定运行
- [ ] 代码覆盖率 ≥ 80%

## Phase 3：整合定位（2-4周）

### 目标
明确与 main 分支的关系，制定长期策略。

### 决策选项

| 选项 | 描述 | 适用条件 |
|------|------|---------|
| A. AGI 容器 | mves 作为框架，main 的 Meta-SME 作为引擎 | Phase 2 验证通过，组件可插拔 |
| B. 实验分支 | mves 专注探索，成熟组件迁移至 main | 部分组件不稳定，但有价值 |
| C. 独立演进 | 保持独立，服务不同场景 | 资源充足，目标用户差异大 |

### 任务清单

- [ ] 与 main 分支维护者正式沟通
  - 内容：验证结果分享、整合意向、接口讨论
  - 产出：会议纪要，初步共识

- [ ] 技术对接分析
  - 内容：main Meta-SME 与 mves 组件的接口映射
  - 产出：技术对接文档

- [ ] 整合路线图（如选择 A 或 B）
  - 内容：分阶段整合计划、版本协调、维护责任
  - 产出：MOSS-Integration-Roadmap.md

### Phase 3 完成标准

- [ ] 与 main 分支达成明确协议
- [ ] 发布整合路线图（或独立演进声明）
- [ ] 更新版本标签（v8.0.0-beta → v8.0.0-rc 或保持 beta）
