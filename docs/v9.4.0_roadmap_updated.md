# MOSS v9.4.0 Roadmap: Quality & Plugin Architecture (Updated)

**Target Release:** 2026 Q4  
**Theme:** Code Quality, Plugin System & mves Integration  
**Status:** Phase 1 Complete ✅, Phase 2-3 In Progress

---

## 更新说明 (基于 Manus 评价)

Manus 评价指出：
1. **mves 分支在科学严谨性和 Agent 实用化方面已远超 main**
2. **main 分支过于偏向代码重构工具，偏离了 "Self-Driven System" 核心目标**
3. **需要文档整合、成本优化、复杂性管理**

**v9.4.0 调整方向**: 在保持工程化优势的同时，通过 Plugin 系统整合 mves 的 Agent 能力。
